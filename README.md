# Máy tính xà phòng

Máy tính xà phòng handmade tiếng Việt: tính xút NaOH/KOH, nước, tinh dầu, phụ gia, chỉ số độ cứng và độ bọt, giá thành, nhãn thành phần INCI, 12 mẫu xà phòng có sẵn.

- Trang web: https://maytinhxaphong.netlify.app
- Toàn bộ trang nằm trong một file: `index.html`. Sửa file này rồi lưu (commit) là trang tự cập nhật.
